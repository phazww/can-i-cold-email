# Can I cold email?

B2B cold email rules by country, each linked to the law or the regulator, plus a lead list checker that runs entirely in the browser.

Live: https://phazww.github.io/can-i-cold-email/

- `data.js` holds the rules and sources for each country.
- `node build.js` regenerates `index.html`, the country pages in `c/`, `sitemap.xml` and `robots.txt`.

This is a research summary, not legal advice. Corrections are welcome: open an issue or write to [@phaz_dev](https://x.com/phaz_dev).
